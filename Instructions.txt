1. Comparación de Artículos

Objetivo
Construir una API backend simplificada que suministre detalles de productos para ser usada en una función de comparación de artículos. Tu implementación debe seguir las mejores prácticas establecidas para el backend, proporcionando endpoints claros y eficientes para recuperar los datos necesarios para las comparaciones de productos.

Requisitos

Backend: Desarrollo de API
Endpoint de la API:

Construir una API RESTful básica que devuelva detalles de múltiples artículos a comparar.

La API debe proporcionar campos como: nombre del producto, URL de la imagen, descripción, precio, calificación y especificaciones.
